# BrainRing
嵌赛国二项目（附演示视频链接）
基于STM32H7和RTOS的专注力脑波头环与专注力平衡台
项目简介：面向专注力训练的闭环控制设备，L431端采集脑波，H743端处理脑波数据，利用双通道脑波转化为实时解算的专注度，通过专注度头环和PID控制平衡台和小球。
技术栈：STM32H743、L431，FreeROTS,TOF400C测距,KS1092脑波采集,XY-MBO6BA多主多从，MG90S舵机，PID滤波算法
核心工作与重难点:
1.基于STM32L431+KS1092完成前额双通道脑电信号采集，通过ADC读取原始电压量化值，实现了头环产品的低功耗采集和透传。
2.基于XY-MBO6BA模块实现一从多主通信架构，L431端作为从机以”ch1,ch2\n”格式广播数据，H743端+手机APP端作为双主机并行接收数据，解决多终端数据同步冲突。
3.在H743端设计对每256个采样点计算RMS和Delta并分配主、辅权重双特性融合映射，输出0-100的专注度值并加以7帧滑动窗口平均和一阶低通滤波，区分放松/专注两种状态，识别延迟控制在20ms内，二者区分度满足实时控制要求。
4.设计专注和放松状态机来控制平衡台角度，专注时基于TOF距离差和PID算法实现小球自动回中(角度<1°)，并利用MPU6050进行长周期姿态校；放松时生成幅值40°正弦摆动，结合TOF碰撞检测触发反馈。
5.利用RTOS构建多任务架构，通过队列通信和优先级分级调度，实现了系统20ms周期稳定控制。
